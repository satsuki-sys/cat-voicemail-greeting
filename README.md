Entry for the make.fun competition **Funniest Cat Voicemail Greeting**. `main.py` writes a single one-line voicemail greeting, recorded by a very annoyed cat named Miso, to `/output/entry.txt`.

> You've reached Miso. I'm asleep in a box and you woke me up. Leave a message — I'll knock it off the shelf at 4 a.m.
